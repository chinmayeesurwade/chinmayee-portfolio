# Chinmayee Surwade — Portfolio

Recruiter-focused portfolio for Business Analyst, Technical BA and Data Analyst opportunities.

## Current structure
- Responsive homepage
- Independent Consulting & Analytics section
- Five dedicated client case-study pages
- Professional experience
- Trade Finance portfolio simulation
- Skills and contact sections
- Private phone-number request flow

## Local development
```bash
npm install
npm run dev
```

## Deployment
Import this repository into Vercel and deploy using the Next.js preset.

## Asset checklist
Before final public launch, add the approved portrait, resume PDF and sanitized dashboard images under `public/`. Dashboard visuals should be labelled as portfolio-safe representations when their displayed sample values differ from engagement-level verified outcomes.
